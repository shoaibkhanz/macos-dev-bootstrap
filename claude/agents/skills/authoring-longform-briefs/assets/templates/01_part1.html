Chapter One The shape of a fragment

One paragraph saying what this chapter is for and what the reader will be able to do afterwards. Never a summary of the conclusions — the chapter has not earned them yet.

1.1 What the build does for you

Body prose is justified and hyphenated by the stylesheet; do not override either. Paragraphs after the first are indented automatically, so never insert blank-line spacers or non-breaking spaces to fake vertical rhythm.

Fragment

One ordered HTML file holding a bare sequence of block elements. The build script discovers every NN*.html in the directory and concatenates them in filename order, so a document under construction still renders.

“A quotation earns its callout only when the exact wording carries the weight — a normative must, a number you rely on, or a concession against interest.”

Immediately after a quotation, do something with it: extract the consequence, disagree with it, qualify it, or connect it forward. A quotation followed by the next heading is decoration.

Reading Figure 1
  1. The dark box is the pass that matters. It is the only render whose output is written to disk; the earlier passes exist to discover facts.
  2. The dashed return path encodes iteration, not failure. Injecting page numbers changes line lengths, which can change pagination.
  3. The relationship is fixed-point, not sequential. The loop ends when the anchor map is identical to the previous pass.
  4. What the figure does not show is the structural check that runs before any of this, because it never touches the renderer.
  5. Leave with this: a contents page is only as honest as the pass that measured it.
How to recognise a missing font

Text still renders, so nothing errors — but the measure changes and the page count moves. Verify embedding in the PDF rather than trusting the build log.

The property everything else follows from

If a reader cannot check a claim against a named, dated, addressable source, the claim is decoration. One dark box per chapter; this is that chapter’s.
